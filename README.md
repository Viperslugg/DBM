# **Seq2Seq**

This repository is to build sequence-sequence models for implementing language translation, using PyTorch and Flax libraries for the RNN and transformer implementations respectively.

### **Models**
- An intent-based chatbot that is trained on a limited set of questions and responses.
- Seq2Seq model 1 is a stepping stone to Seq2Seq model 2.

### **About the data**
The data is [the Multi30k dataset](https://huggingface.co/datasets/bentrevett/multi30k), sourced from Hugging Face. It contains thousands of German and English sentence pairs, and is divided into training, test and validation sets.
